# 坦克大战（Battle City）

一个用原生 HTML + Canvas + JavaScript 编写的经典坦克大战游戏，无需任何依赖，直接在浏览器中打开即可游玩。

## 玩法

- 控制你的坦克，消灭场上所有敌方坦克
- 保护地图底部的基地（老鹰），一旦基地被摧毁游戏结束
- 敌方坦克会从顶部三处刷新点不断出现

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / `↑` `↓` `←` `→` | 移动 |
| `空格` / `J` | 射击 |
| `P` | 暂停 / 继续 |

## 地图元素

- 🧱 **砖墙**：可被子弹摧毁
- ⚙️ **钢墙**：不可破坏
- 💧 **水域**：坦克无法通行
- 🌲 **树林**：可通行并隐藏坦克

## 运行

直接用浏览器打开 `index.html` 即可，或使用任意静态服务器：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```
